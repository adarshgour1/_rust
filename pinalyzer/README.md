# Pinalyzer

Pinalyzer is a Rust-based command-line tool for network device monitoring and analysis. It allows you to ping multiple devices, collect latency statistics, and store results in an SQLite database for further analysis.

## Features
- Ping multiple devices (by ID or all at once)
- Collect and store ping statistics (min/avg/max RTT, packet loss, etc.)
- Graceful shutdown with Ctrl+C
- Output in table or JSON format
- Modular codebase for easy extension

## Usage

### Build
```
cargo build --release
mv ./target/release/pinalyzer /usr/local/bin
```

### Example

#### Add a devices
```
$ pinalyzer device create --name local --ip 127.0.0.1 
+----+-------+-----------+
| id | name  | ipaddr    |
+----+-------+-----------+
| 1  | local | 127.0.0.1 |
+----+-------+-----------+

$ pinalyzer device create --name google-switch --ip 8.8.8.8 
+----+---------------+---------+
| id | name          | ipaddr  |
+----+---------------+---------+
| 2  | google-switch | 8.8.8.8 |

```

```
$ sudo ./target/release/pinalyzer device get --all

| id | name          | ipaddr    |
+----+---------------+-----------+
| 1  | local         | 127.0.0.1 |
| 2  | google-switch | 8.8.8.8   |
+----+---------------+-----------+
```

## Code Structure
- `src/main.rs`: Entry point and CLI setup
- `src/cmd/`: Command implementations
- `src/modules/`: Data models and database logic
- `src/plugin/`: Ping logic and statistics
- `src/format/`: Output formatting utilities
- `src/error.rs`: Error types and handling
